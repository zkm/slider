A contemporary, accessible image slider built with vanilla JavaScript. This project demonstrates a responsive image carousel with thumbnail navigation that works across all devices and meets WCAG/508 accessibility standards.

## Features
- Fully accessible with ARIA attributes and keyboard navigation
- Responsive design that works on all screen sizes
- Touch-optimized with swipe gestures and haptic feedback
- Dynamic thumbnail navigation with adaptive visibility
- No dependencies - pure vanilla JavaScript
- Modern animations and transitions
- Screen reader announcements
- Mobile-first approach

## Getting started
### Dependencies
- None! This slider is built with vanilla JavaScript, CSS, and HTML

### Browser Support
- All modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile browsers with touch support

## Accessibility Features
- ARIA roles and attributes
- Keyboard navigation (arrow keys)
- Focus management
- Live region announcements
- High contrast controls
- Touch feedback

## Mobile Enhancements
- Swipe gesture support
- Optimized touch targets
- Responsive thumbnail display
- Visual feedback for interactions
